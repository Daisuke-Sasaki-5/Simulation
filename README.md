# Farm Simulation
## ゲーム概要
* 作物を育てお金を稼ぐ簡単なシミュレーションゲーム

## 制作環境
* C++
* VisualStdio
* DXLib

## ゲームルール
* 3種類の作物を育て、お金を稼ぐ
* 種植え、日数経過、水タンクの補充などでお金を都度使用
* 作物の水ゲージが０になると作物が枯れる
* 所持金が０を下回るとゲームオーバー

## 操作方法
* ←→キーで作物スロット選択
* 1 ニンジンの種選択
* 2 トマトの種選択
* 3 かぼちゃの種選択
* P 植える
* Enter 収穫
* Space 日数を進める
* C 枯れた作物削除
* R 水タンクの補充
* W 作物に水を与える

## 使用アセット
* テキスト画像 CoolText 使用
* 作物、スロット、背景画像等　AI生成　使用
* 使用BGM　カエルのピアノ
